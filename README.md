# Tillsoft - Setup Installer

This repository holds the official NSIS setup installers for [Tillsoft](https://github.com/TillSoft/Tillsoft-App), the offline desktop point of sale and CRM for retail and wholesale.

## Downloads

Go to [Releases](https://github.com/TillSoft/Tillsoft-Setup/releases) to download the latest installer (`Tillsoft_<version>_x64-setup.exe`).

Installed copies update themselves from the latest release.
